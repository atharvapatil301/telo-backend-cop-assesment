# Submission Instructions

Please submit your work as a GitHub repository link.

## Required Deliverables

Your repository should contain:

- working source code
- a `README.md`
- setup instructions
- a clear description of assumptions and tradeoffs
- API usage examples
- tests
- sample data or seed instructions
- a `.env.example` if environment configuration is required

## README Expectations

Your README should include:

- problem summary
- architecture overview
- local setup steps
- how to run the service
- how to run tests
- API endpoint summary
- design decisions
- known limitations
- what you would improve with 1-2 more days

## Submission Format

Please email:

- your repository link
- which task you chose
- any notes we should read first

Optional but appreciated:

- a short Loom or walkthrough video
- Postman collection or equivalent API examples
- screenshots of docs or running flows

## Timeline

Please submit within 7 days of receiving the assignment.

If you need a short extension, reply to the assignment email and let us know.

## Rules

- you may use AI tools
- you may use third-party libraries
- keep the scope reasonable
- do not build unnecessary features at the expense of code quality

## What Matters Most

We care more about:

- correctness
- clean implementation
- backend reasoning
- schema choices
- testing
- tradeoff clarity

than about having the most features.
